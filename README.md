# @SantaHalloween2026bot — хэллоуинская раздача на Vercel

Без сервера и включённого компьютера: функции Vercel + webhook Telegram. Данные — в бесплатном Redis от Upstash, он подключается прямо в Vercel.

## Как работает бот

1. Человек подаёт заявку в закрытый канал → бот сразу пишет ему в личку и одобряет заявку.
2. «Забрать набор» → бот проверяет подписку → два пути:
   - **свой публичный канал от 5 подписчиков** (переменная `MIN_SUBS`) → бот собирает обложку с фото человека → даёт готовый пост → человек публикует его и присылает ссылку → бот проверяет, что в посте есть @SantaHalloween2026bot → 5 PDF. Один канал — один подарок;
   - **канала нет** → оплата **499 ⭐** → 5 PDF.
3. Раз в день бот перепроверяет посты старше суток и пишет вам, если пост удалили.
4. После 8 ноября 23:59 (Мадрид) бот отвечает «раздача завершилась». Заявки в канал продолжает одобрять.

Админ-команды (только с вашего аккаунта): `/stats`, `/export` (таблица участников CSV), `/refund <user_id>` (вернуть звёзды), команды Лорда Морока `/morok_*` — см. ниже.
Для всех: `/terms`, `/paysupport` — Telegram требует их для ботов с оплатой.

## По шагам

### 1. Импорт в Vercel

vercel.com → **Add New → Project** → импортируйте репозиторий `kristinaperez/halloween_bot`.
Framework Preset — **Other**. Остальное подхватится из `vercel.json`, поля не трогайте.

### 2. Подключить Redis

В проекте: **Storage** (или **Marketplace**) → **Upstash → Redis** → Create → бесплатный план → **Connect to project**.
Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.

### 3. Переменные окружения

**Settings → Environment Variables** (Production):

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен @SantaHalloween2026bot из BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка (латиница, цифры, `-`, `_`), например результат `node -e "console.log(crypto.randomUUID())"` |
| `CHANNEL_ID` | `-1003772984999` |
| `ADMIN_ID` | `6713072327` |
| `CHANNEL_INVITE_LINK` | ваша пригласительная ссылка с заявками (`https://t.me/+...`) |
| `CRON_SECRET` | любая случайная строка — защищает ежедневную проверку постов |

Необязательные (уже со значениями по умолчанию): `DEADLINE=2026-11-08T23:59:00+01:00`, `PRICE_STARS=499`, `MIN_SUBS=5`, `CONTACT=@KristinaPerez9`.

После добавления переменных: **Deployments → … → Redeploy**. Откройте `https://<проект>.vercel.app/api/telegram` — должно быть «Halloween bot webhook is alive 🎃».

### 4. Подключить webhook

На компьютере (Node.js 22+), в папке проекта:

```bash
npm install
```

Создайте локальный `.env` с тремя значениями: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (тот же, что в Vercel) и `SITE_URL=https://<проект>.vercel.app`. Затем:

```bash
npm run telegram:webhook          # подключить
npm run telegram:webhook status   # проверить: last_error должен быть null
```

Webhook подписан на заявки в канал и оплату звёздами — без этого бот их не увидит.

### 5. Права бота в канале

Канал → Администраторы → `@SantaHalloween2026bot` → право **«Пригласительные ссылки» / «Добавление участников»**. Без него бот не одобряет заявки и не видит подписку.

### 6. Проверка

Со второго аккаунта: пригласительная ссылка → бот пишет в личку, заявка одобрена → «Забрать набор» → проверить оба пути (окно оплаты должно открыться; платить не обязательно). С вашего аккаунта — `/stats`.

## После 8 ноября

Бот сам перестаёт выдавать набор. Перед отключением скачайте `/export`. Отключить: удалить проект в Vercel или webhook (`deleteWebhook`).

## Изменить без программиста

Переменные в Vercel (`DEADLINE`, `PRICE_STARS`, `MIN_SUBS`) → Redeploy. PDF лежат в `assets/kit/`, картинки — в `assets/`.

## Лорд Морок: «Дело четырёх блокировок»

Первое интерактивное событие канала «Кристина строит миры». В канале появляется злодей Лорд Морок, проводит шуточный суд над **вымышленным** Теневым странником № 47, Кристина его осаживает, и Морок нехотя издаёт Указ № 001: порог для подарка снижен со 100 до 5 подписчиков. В конце — голосование «Что делать с Мороком?», его итог задаёт следующую серию.

Изгнания — только сюжет: бот никого не удаляет из канала и нигде не показывает, кто заблокировал бота. Тексты сценария — в `server/morok.ts`, движок — в `server/scenario.ts`, картинки и промпты к ним — в `assets/morok/`.

### Сцены (12 шагов)

1. Кристина: «Хэллоуин закончился… кажется, ушли не все гости» — публикуешь сама
2. Праздничный бот: «У нас происшествие! Четверо меня заблокировали» + картинка 1
3. Появление Морока + картинка 2
4. Монолог «ЧЕТВЕРО» (без звука)
5. Магический трибунал, дело № 001 + картинка 3
6. Магический протокол + анимация изгнания
7. Кристина: «Морок, ты вообще нормальный?!» (без звука)
8. Морок: «Но они заблокировали бота!» (без звука)
9. Кристина: «Сделай что-нибудь полезное — убери порог» (без звука)
10. Морок: «Демократия. Отвратительно. …Но так уж и быть» (без звука)
11. Указ Лорда Морока № 001 с кнопками «🎁 Поздравить своё сообщество» и «😈 Вызвать Морока»
12. Голосование «Что нам делать с Лордом Мороком?»

Каждый следующий шаг публикуется **только по твоей кнопке** «▶ Следующая сцена» в личке с ботом — паузы выбираешь сама, бот подсказывает, сколько подождать. Твои реплики бот присылает тебе: публикуешь от себя и жмёшь «✅ Я опубликовала» или поручаешь боту «🤖 Пусть опубликует бот». Реплики внутри диалога уходят без звука, чтобы не заспамить подписчиков уведомлениями.

«😈 Вызвать Морока» под указом показывает всплывающее окно со случайной репликой злодея. Боту ничего не пишется в личку, нажавший не сохраняется в базу.

### Команды (только с аккаунта ADMIN_ID)

| Команда | Что делает |
|---|---|
| `/morok_preview` | весь сценарий тебе в личку — в канал ничего не уходит |
| `/morok_test` | весь сценарий в тестовый канал `TEST_CHAT_ID` — с настоящими подписями и кнопками |
| `/morok_start` | запуск в канал после подтверждения кнопкой |
| `/morok_stop` | пауза; продолжить — `/morok_start` или кнопка «▶ Продолжить» |
| `/morok_status` | состояние: какой шаг, чего не хватает, итог голосования |
| `/morok_start again` | показать сценарий ещё раз с начала (без `again` повтора не будет) |

После последнего шага бот пришлёт кнопку «🗳 Закрыть голосование и узнать итог».

### Защита от повторов

Уже опубликованные шаги не публикуются снова — ни после перезапуска, ни при двойном нажатии, ни при повторной доставке апдейта от Telegram. Если связь оборвалась посреди отправки, бот сам не повторяет, а спрашивает: «Пост в канале есть?» — «✅ Есть, идём дальше» или «🔁 Нет, отправить снова».

### Запуск по шагам

1. **Картинки.** Сгенерируй по `assets/morok/PROMPTS.md` три картинки и положи их в `assets/morok/` под указанными именами. Анимация изгнания уже готова. Без картинок посты уйдут текстом.
2. **Порог.** Если в Vercel задана переменная `MIN_SUBS=100` — поменяй на `5` или удали (по умолчанию теперь 5).
3. **Права.** У @SantaHalloween2026bot в канале должно быть право «Публикация сообщений».
4. **Отдельный бот Морока (по желанию, но эффектнее).** В @BotFather создай бота, например «Лорд Морок», поставь ему аватар (картинка 2). Добавь его админом канала с правом публикации. В Vercel: `MOROK_BOT_TOKEN` = его токен. После деплоя на компьютере: `npm run telegram:webhook morok` (в локальном `.env` нужен `MOROK_BOT_TOKEN`). Без этого бота Морок говорит через праздничного бота с подписью «😈 Лорд Морок:» в тексте.
5. **Подписи авторов (по желанию).** Канал → Настройки → «Подписывать сообщения». Тогда в Vercel поставь `CHANNEL_SIGNATURES=1` — бот уберёт подписи из текста там, где пост и так подписан автором. Проверь в тестовом канале, как Telegram подписывает посты ботов.
6. **Тестовый канал.** Создай закрытый канал, добавь туда ботов админами с правом публикации, его id впиши в Vercel как `TEST_CHAT_ID`. Id можно узнать, переслав пост из канала боту @userinfobot.
7. **Redeploy** в Vercel.
8. `/morok_preview` → `/morok_test` → смотришь, как выглядит → `/morok_start` → «🚀 Да, запустить».

## Для разработки

```bash
npm install
npm run check   # проверка типов
npm test        # сценарии бота на имитации Telegram и Redis
```

## Ограничения

- Проверка поста работает только для **публичных** каналов: бот читает публичную страницу поста.
- Ежедневный cron — ограничение бесплатного тарифа Vercel (Hobby): чаще раза в день нельзя.
