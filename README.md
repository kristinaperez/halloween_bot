# @SantaHalloween2026bot — хэллоуинская раздача на Netlify

**Без сервера, без VPS, без включённого компьютера.** Как овощной бот: функции Netlify + webhook Telegram. Данные хранятся в **Netlify Blobs** — встроенном хранилище Netlify, его не нужно включать отдельно, и кредиты Database оно не тратит.

## Как работает бот

1. Человек подаёт заявку в закрытый канал → бот сразу пишет ему в личку и одобряет заявку.
2. «Забрать набор» → бот проверяет подписку → два пути:
   - **свой публичный канал от 100 подписчиков** → бот собирает обложку с фото человека → даёт готовый пост → человек публикует его и присылает ссылку → бот проверяет, что в посте есть @SantaHalloween2026bot → 5 PDF. Один канал — один подарок;
   - **канала нет** → оплата **499 ⭐** → 5 PDF.
3. Раз в час бот смотрит посты, которым больше суток, и пишет вам, если пост удалили.
4. После 8 ноября 23:59 (Мадрид) бот отвечает «раздача завершилась». Заявки в канал продолжает одобрять.

Админ-команды (только с вашего аккаунта): `/stats`, `/export` (таблица участников CSV), `/refund <user_id>` (вернуть звёзды).
Для всех: `/terms`, `/paysupport` — Telegram требует их для ботов с оплатой.

## По шагам

### 1. Загрузить в GitHub

Создайте репозиторий (можно приватный) и загрузите **содержимое этой папки**, чтобы `netlify.toml`, `package.json`, `server`, `netlify`, `assets`, `kit` лежали в корне. `.env` и `node_modules` не загружайте — они в `.gitignore`.

### 2. Подключить к Netlify

Add new project → Import from Git → ваш репозиторий. Настройки уже в `netlify.toml`, поля можно не трогать:

| Настройка | Значение |
|---|---|
| Base directory | пусто (корень) |
| Build command | из `netlify.toml` |
| Publish directory | `public` |
| Functions directory | `netlify/functions` |

### 3. Переменные окружения

**Project configuration → Environment variables**, scope — **Functions**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен @SantaHalloween2026bot из BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка (латиница, цифры, `-`, `_`), например результат `node -e "console.log(crypto.randomUUID())"` |
| `CHANNEL_ID` | `-1003772984999` |
| `ADMIN_ID` | `6713072327` |
| `CHANNEL_INVITE_LINK` | ваша пригласительная ссылка с заявками (`https://t.me/+...`) |

Необязательные (уже со значениями по умолчанию): `DEADLINE=2026-11-08T23:59:00+01:00`, `PRICE_STARS=499`, `MIN_SUBS=100`, `CONTACT=@KristinaPerez9`.

Запустите **Deploy**. Появится адрес вида `https://имя.netlify.app`.

### 4. Подключить webhook

На компьютере (Node.js 22+), в папке проекта:

```bash
npm install
```

Создайте локальный `.env` по образцу `.env.example` с тремя значениями: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (тот же, что в Netlify) и `SITE_URL=https://имя.netlify.app`. Затем:

```bash
npm run telegram:webhook          # подключить
npm run telegram:webhook status   # проверить: last_error должен быть null
```

Webhook подписан на заявки в канал и оплату звёздами — без этого бот их не увидит.

### 5. Права бота в канале

Канал → Администраторы → `@SantaHalloween2026bot` → право **«Пригласительные ссылки» / «Добавление участников»**. Без него бот не одобряет заявки и не видит подписку.

### 6. Проверка

Со второго аккаунта: перейти по пригласительной ссылке → бот пишет в личку, заявка одобрена → «Забрать набор» → проверить оба пути (окно оплаты должно открыться; платить не обязательно). С вашего аккаунта — `/stats`.

## После 8 ноября

Бот сам перестаёт выдавать набор. Перед отключением скачайте `/export`. Отключить бота: `deleteWebhook` или просто удалите сайт в Netlify.

## Изменить без программиста

Переменные в Netlify (`DEADLINE`, `PRICE_STARS`, `MIN_SUBS`) → Deploys → Trigger deploy. PDF лежат в `kit/`, картинки — в `assets/`.

## Ограничения

- Проверка поста работает только для **публичных** каналов: бот читает публичную страницу поста.
- Функция Netlify должна уложиться в 10 секунд. Сборка обложки и отправка 5 PDF занимают 2–4 секунды; после первой выдачи PDF отправляются из кэша Telegram мгновенно.
